Add ScrollCoordinator with collapsible headers, persistent toolbars, nested scrolling, and whole-page or per-page refresh using the public native elements. Align refresh configuration, callbacks, and start/finish methods with FeedList while keeping the implementation independent. Include aggregate exports, API documentation, component guidance, and themed examples, including a dedicated ViewPager with TabGroup navigation and an independent List in each page.

Disable inner List bounces in the whole-page refresh example so pull gestures and rebound are handled by the outer refresh.
