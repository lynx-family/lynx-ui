# @lynx-js/lynx-ui-select

Headless Select component for lynx-ui.

## Installation

```bash
npm install @lynx-js/lynx-ui-select
```

## Usage

```tsx
import { Select } from '@lynx-js/lynx-ui-select'

<Select
  options={[
    { label: 'Apple', value: 'apple' },
    { label: 'Orange', value: 'orange' },
  ]}
/>
```
