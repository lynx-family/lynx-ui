## Structure

```jsx
<SheetRoot snapPoints={['fit', '80%']}>
  <SheetView>
    <SheetBackdrop clickToClose />
    <SheetContent>
      <SheetHandle />
      {content}
    </SheetContent>
  </SheetView>
</SheetRoot>
```

## Key Concepts

- `snapPoints` supports pixel numbers, percentages such as `'50%'`, and `'fit'` for content-driven height.
- Use `show` with `onShowChange` for controlled mode, or `defaultShow` and `SheetRootRef` methods for uncontrolled mode.
- `SheetRootRef` exposes `open`, `close`, `snapTo`, `expand`, and `collapse` for imperative control.
- If you want the sheet to start opened, see the `ControlledOpen` and `DefaultOpen` examples.
- `style` on `SheetContent` applies to the outer sheet surface, while `innerStyle` and `innerClassName` style the inner measured content area.
- Use `handleOnly` when only the handle should start drag gestures. Use `container` and `overlayLevel` on `SheetView` when the sheet needs to render in a higher native layer.
- For larger layouts, see the `Tablet` example for a sheet surface that stays readable on wide screens.
