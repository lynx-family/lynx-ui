# @lynx-js/lynx-ui-swipe-action

一个适用于 ReactLynx 的滑动操作组件，通过主线程手势提供可滑动列表项基础能力。

## 安装

强烈建议通过主包 `@lynx-js/lynx-ui` 安装并使用该包：

```bash
# pnpm（推荐）
pnpm add @lynx-js/lynx-ui

# npm
npm install @lynx-js/lynx-ui

# yarn
yarn add @lynx-js/lynx-ui
```

_（如有需要，也可以通过 `pnpm add @lynx-js/lynx-ui-swipe-action` 单独安装该包）_

## 使用

[查看完整示例](https://github.com/lynx-family/lynx-ui/tree/main/apps/examples/SwipeAction)

## 组件结构

```tsx
<SwipeAction>
  {/* Your content */}
</SwipeAction>
```
