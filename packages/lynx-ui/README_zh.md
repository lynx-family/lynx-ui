# @lynx-js/lynx-ui

`@lynx-js/lynx-ui` 是 ReactLynx 官方无样式 UI 组件库，用于构建灵活、通用且高性能的 Lynx 组件。

## 介绍

Lynx UI 通过前端组件扩展原生组件能力，帮助团队构建高性能、接近原生体验且具备广泛兼容性的 Lynx 组件生态。

该包会统一和封装底层原子能力，让业务可以在不同平台上使用一致的 ReactLynx 组件模式。

## 安装

`lynx-ui` 支持完整引入，也支持按组件单独引入。

```bash
pnpm add @lynx-js/lynx-ui
```

## 使用

当你希望通过统一入口使用 Lynx UI 组件时，推荐从主包中引入组件。构建工具链支持 tree-shaking。

## 兼容性

- LynxSDK: >= 3.2

单个组件可能有额外的兼容性要求。
