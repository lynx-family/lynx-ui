## 0.2.1

### Patch Changes

- Migrate the LUNA foundation packages from shim packages to source-built packages ([#239](https://github.com/lynx-family/lynx-ui/pull/239))
  in lynx-ui.

  The packages now build from migrated source with the local Rslib/Rsbuild 2.x
  toolchain instead of syncing upstream distributions. Public package paths, CSS
  entry points, Tailwind entry points, and type entry points remain available
  through package exports. The luna-reactlynx ESM entries now resolve to
  source-built `.js` files generated by Rslib, and meta-only theme color snapshots
  are now frozen consistently with values-backed theme snapshots.
